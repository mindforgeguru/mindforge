What sits
behind
each door.

Four people, one record. Nobody re-enters what somebody else already wrote down, and the letters here are the same letters on the doors above.

RefDoorOpens onto
A Admin The school office. Add and remove users, set fee structures, open an academic year, build the timetable. Set once, used by everybody else all year.
B Teacher Generate a test from a chapter PDF, mark attendance for the class, grade the written answers on one screen, and broadcast a notice that reaches every parent's phone.
C Student What's due today, the test to attempt, the score when it lands, the timetable for tomorrow, and how many days present this month.
D Parent Marks, attendance, homework and fees for their own child, without chasing a teacher or waiting for the next meeting. Signs in alongside the student.
